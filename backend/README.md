# Backend Lojinha — CRUD

Inicie com `.\mvnw.cmd spring-boot:run` no Windows ou `./mvnw spring-boot:run` no Linux/macOS. Consulte `../README-BACKEND-CRUD.md` para rotas, exemplos do Postman e requisitos.

A API usa SQLite no arquivo `lojinha.db`, porta 8081 e mantém os nomes de campos consumidos pelo frontend.
